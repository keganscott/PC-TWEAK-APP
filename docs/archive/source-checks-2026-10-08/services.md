## Notes
- The scanner comment at scanner.rs:363 calls the 2027-10-12 date "a single source" and leaves it out of the copy. Microsoft's own ESU page now gives October 12, 2027, so the date can be named if Kegan wants it. The same page offers ESU at no extra cost (settings sync or Rewards points), so the current wording "free security updates … unless enrolled" is still accurate.
- For the scheduled tasks, Microsoft confirms the task names Consolidator, Microsoft-Windows-DiskDiagnosticDataCollector and Proxy, but no Microsoft page found gives their Task Scheduler folders, or any trace of UsbCeip or ProgramDataUpdater. Each of those three is described as collecting data only for users who opted in to CEIP.
