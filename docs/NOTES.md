# Open items

**Kinds:** BLOCKED = needs Kegan or a real machine. TODO = doable now. ASSUMED = a default I picked; change it if wrong. NOTE = for the record.

**Fastest way to close most BLOCKED items:** run `peaktweaks-field-check.exe` on a real PC (`docs/FIELD_CHECK.md`); it covers N22, N23, N24, N25, N26, N28, N33, N34, N39 and N43 in one run.
