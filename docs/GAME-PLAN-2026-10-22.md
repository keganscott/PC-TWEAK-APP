# PeakTweaks game plan (2026-10-22)

Kegan's goal: the best PC tweaking app there is, built for people with low and mid-range PCs, so they can compete with the hardware they already own.

This plan reviews where the app stands (latest branch `claude/peaktweaks-windows-setup-sw5aub-ax2mx0`, 47cccae, green on Windows CI run 38930001230), compares it with the market, and lays out the work in order.

## 1. Where PeakTweaks stands

**Strong already, and rarer than it looks:**
- About 60 one-click tools covering Windows, gaming, input, privacy, power, services, network (Nagle, adapter settings, DNS, QoS, TCP), NVIDIA and AMD driver settings, per-game settings files, MSI mode, startup apps and refresh rate.
- "Apply the safe set" and presets.
- A safety net no competitor has: restore point first, a backup and journal record before every change, Undo, Undo all, and offline recovery files.
- Proof: before/after frame-time measurement on the user's own PC, with an honest verdict.
- A live dashboard, a connection check (ping, jitter and loss to the router and the internet), a memory cleaner, junk cleanup, drive optimisation, a mouse polling-rate check, a driver tool, Gaming Mode, and an 11-check PC scan.

**What holds it back today:**
1. **Not proven on real PCs.** Restore-point creation has never succeeded on a client PC (N24). Many registry paths still carry VERIFY. The Phase 3/4/5 gates (real-PC field check, real game runs, three hand-checked PCs) are not met. Hone's Trustpilot shows what happens without this: most complaints are boot problems, driver conflicts and changes that took a day to undo.
2. **Code spread over five branches and four open PRs** (#1, #2, #4, #5). Nobody can ship from that.
3. **Built for people who already know what they want.** A low-end PC owner needs to be told: "your PC is held back by X, here is the fix, here is what it changed".
4. **Not a product yet.** There is no installer, no code signing (SmartScreen blocks first launches), no updates, and no pricing (plan section 11).

## 2. What others have that PeakTweaks lacks

| Feature | Who has it | For low-end PCs | How PeakTweaks can do it, inside its rules |
|---|---|---|---|
| Frame generation and upscaling for any game | Lossless Scaling (~$7), Magpie (free), AMD AFMF/RSR, NVIDIA Smooth Motion/NIS | The biggest single lever on a weak GPU: render at a lower resolution, upscale | Phase 1: detect the GPU and switch on the driver's own upscaler and frame generation where supported (NIS via NvAPI, RSR/AFMF via ADLX, both modules exist). Phase 3: our own window upscaler (AMD FSR 1 is MIT-licensed; capture via Windows.Graphics.Capture, no injection) |
| Frame-rate cap for steady frame pacing | RTSS, NVIDIA/AMD drivers | A cap below what the GPU can hold removes stutter on weak PCs | Driver-level cap per game (NVIDIA Max Frame Rate, AMD FRTC/Chill). No injection, so the never-do list holds |
| Background hog control while playing | Process Lasso ProBalance, Razer Cortex | Weak CPUs suffer most from background spikes | Gaming Mode already exists. Add ProBalance-style lowering of other programs' priority while a game runs (never the game's affinity) |
| Windows repair | WinUtil | Old, broken installs are common on cheap PCs | One "Repair Windows" action: SFC and DISM, Windows Update reset, shown and logged |
| App installs and debloat | WinUtil | Preinstalled junk on cheap laptops | Debloat stays out (not cleanly undoable). Offer an uninstall list of Store apps with a reinstall button |
| In-game "pro" settings | Hone, Razer Cortex | Big FPS lever | `ini.rs` and profile packs exist (N55, N138). Add low-end presets per game, not only competitive ones |
| Route optimisation | ExitLag | Ping | Needs a server network; out of scope (catalogue E1) |

## 3. What nobody else does (where PeakTweaks can lead)

1. **"What's holding your PC back" report, in plain words.** Built on the scan, it ranks bottlenecks by size. For example: "Your memory runs in single channel: a second matching stick is the biggest upgrade for this PC (integrated graphics often gain the most)." Then XMP off, a game on a hard drive, a laptop on battery or in power-saving mode, thermal throttling. The cheapest fix comes first and nothing is sold. No competitor tells people the truth about their hardware.
2. **Throttling and thermals while playing.** GPU via NVML (exists). CPU via clock and performance counters over time, without any kernel driver. The laptop's Windows power mode and charger state. Says "your laptop slows down after 4 minutes of play: clean the vents, use a stand, plug in", with the measurement as evidence.
3. **Stutter doctor.** Proof already captures frame times. Line up the spikes with what happened at that moment (background CPU spikes, memory pressure, page file on a hard drive, shader compilation on first play) and name the likely cause.
4. **Keeps the PC optimized.** Windows updates quietly reset settings. PeakTweaks already detects drift (`Drifted`). Add a weekly check that says "Windows Update undid 3 of your changes, put them back?", one click.
5. **Proven, not promised.** Every change can show its measured effect on this PC (Proof), and "no measurable change" is reported honestly. That is the answer to the "is it placebo" question every optimizer gets.
6. **Low-end mode per game, one click.** In-game settings preset, render resolution and driver upscaling, frame cap, Gaming Mode, then a Proof run to show the result.

## 4. The plan, in order

### Phase A: make what exists real (2-3 weeks)
1. **One branch.** Merge `-ax2mx0` (and `project-thread-rkugxj` if still needed) into one line, close the stale PRs, Windows CI green. Kegan merges; the agents stop splitting work across branches.
2. **Real-PC test on Kegan's PC** with the one-click script (`scripts\test-on-pc.cmd`, N126): restore-point creation (N24), every tool applied, checked and undone, the field check. Then two more PCs, one low-end (ideally a laptop with integrated graphics, the main audience) and one mid-range. Close VERIFY markers with that evidence.
3. **Fix what the test finds** before adding anything.

### Phase B: the low-end core (3-5 weeks)
1. "What's holding your PC back" report (3.1), as the new Home.
2. Driver upscaling and frame generation switch-on where the GPU supports it, plus a driver-level frame cap per game (section 2).
3. Throttling and thermals while playing, plus the laptop checks (3.2).
4. Background hog control while playing (ProBalance-style).
5. Low-end presets for the main games (Fortnite, Roblox, Minecraft, Valorant, CS2) and "Low-end mode" per game (3.6).
6. Weekly "keep optimized" check (3.4).

### Phase C: what nobody has (4-8 weeks)
1. Stutter doctor (3.3).
2. PeakTweaks Upscale: an FSR 1 window upscaler for games without their own upscaler (MIT-licensed shader; capture, no injection).
3. Repair Windows (SFC/DISM/Update reset) and the Store-app uninstall list.

### Phase D: ship it as a product (parallel, needs Kegan)
1. **Code-signing certificate** (OV or EV): without it, SmartScreen scares off most first-time users.
2. **Installer and updates** (Tauri bundle + updater). Updates need the network, so it is Kegan's call (the "no network" promise).
3. **Pricing and tiers** (plan section 11): free scan and safe set; paid for Proof, per-game modes and advanced tools, as a one-time price or a cheap subscription.
4. **Website, Discord, a crash-report button the user presses** (no automatic telemetry).

## 5. Decisions Kegan owes

1. Merge the branches into one (A.1): yes or no.
2. Run the real-PC test now (A.2), and find two more PCs, one of them low-end.
3. Software updates over the network (D.2): yes or no.
4. Buy a code-signing certificate (D.1).
5. Pricing (D.3, plan section 11).
6. PeakTweaks Upscale (C.2) is the largest build here: go or not.
